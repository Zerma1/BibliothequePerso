# Bibliothèque perso — version de test 0.2.5-test (Windows)

Nouveautés : voir `docs/VERSIONS.md`. Tests à faire : `testUtilisateur/plan_de_tests_v0.2.5-test.md`
(et, si ce n'est pas déjà fait, ceux des 0.2.2-test et 0.2.3-test avec cette même version).

## Avant la mise à jour
Fermez l'ancienne version. La base de données passe en réparée automatiquement au premier lancement si besoin : par
prudence, copiez d'abord le dossier `%APPDATA%\io.github.zerma1\bibliotheque_perso` (à coller dans
la barre d'adresse de l'Explorateur) vers un autre endroit. Vos chapitres téléchargés ne sont pas
modifiés.

## Installation
1. Dézipper `bibliotheque_perso-0.2.5-test-windows.zip` (vous pouvez remplacer le dossier de la
   version précédente).
2. Lancer `bibliotheque_perso.exe` (garder les autres fichiers, dont `WebView2Loader.dll`, et le
   dossier `data` à côté).
3. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires »
   puis « Exécuter quand même ».

Le navigateur intégré utilise Microsoft Edge WebView2, déjà présent sur Windows 11.
