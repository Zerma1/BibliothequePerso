# Bibliothèque perso — version de test 0.2.1-test

Nouveautés et limites : voir `docs/VERSIONS.md`. Tests à faire : `testUtilisateur/plan_de_tests_v0.2.1-test.md`.

## Avant la mise à jour (PC qui a déjà la version précédente)
La base de données sera mise à jour automatiquement au premier lancement. Par prudence,
sauvegardez-la d'abord : copiez le dossier `%APPDATA%\io.github.zerma1\bibliotheque_perso`
(à coller dans la barre d'adresse de l'Explorateur) vers un autre endroit.
Vos chapitres téléchargés sont dans `Documents\bibliotheque_perso` et ne sont pas modifiés.

Après la mise à jour : pour suivre un titre sur deux sites (ex. Potion-danomi sur MangaDex et
Scan-Manga), ouvrez sa fiche, section « Sites », puis « Ajouter un autre site ».

## Windows
1. Fermer l'ancienne version si elle est ouverte.
2. Dézipper `bibliotheque_perso-0.2.1-test-windows.zip` (vous pouvez remplacer le dossier de
   la version précédente).
3. Lancer `bibliotheque_perso.exe` (garder les autres fichiers et le dossier `data` à côté).
4. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires »
   puis « Exécuter quand même ».

## Android
1. Copier `bibliotheque_perso-0.2.1-test-android.apk` sur le téléphone et l'ouvrir : il
   remplace la version précédente en gardant vos données.
2. Ouvrir l'application une fois pour relancer la recherche des nouveaux chapitres en
   arrière-plan.

## Linux
Construite automatiquement par GitHub : onglet « Releases » du dépôt, version
0.2.1-test, fichier `bibliotheque_perso-0.2.1-test-linux.tar.gz` (à décompresser, puis lancer
`bibliotheque_perso`). Si la compilation automatique a échoué, elle n'est pas encore disponible.
