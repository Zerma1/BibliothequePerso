# Bibliothèque perso — version de test 0.1.0-test.1

Nouveautés et limites : voir `docs/VERSIONS.md`.

## Windows
1. Dézipper `bibliotheque_perso-0.1.0-test.1-windows.zip` dans un dossier de votre choix.
2. Lancer `bibliotheque_perso.exe` (garder les autres fichiers et le dossier `data` à côté).
3. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires »
   puis « Exécuter quand même » (l'application n'est pas signée).

## Android
1. Copier `bibliotheque_perso-0.1.0-test.1-android.apk` sur le téléphone.
2. L'ouvrir et autoriser l'installation depuis cette source si Android le demande.
3. Ouvrir l'application une fois pour activer la recherche des nouveaux chapitres en arrière-plan.

L'APK est signé avec une clé de développement : une future version signée autrement
demandera de désinstaller celle-ci (les chapitres téléchargés seront à refaire).
